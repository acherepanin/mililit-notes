## Anti-Patterns Verdict

**LLM assessment:** Не выглядит как чистый AI-slop-лендинг, но есть узнаваемые «AI/SaaS 2024» следы в рабочей зоне: мульти-акцентная палитра (cyan + purple + magenta), декоративные AmbientCubes на auth/sidebar/workspace, пульсирующий AI FAB с частицами и glow. Это конфликтует с PRODUCT.md/DESIGN.md («Trusted Workspace 2.0», AI — capability not brand).

**Deterministic scan:** 2 warning `side-tab`:
- `styles.css:3117` — `blockquote` в редакторе (семантика контента; возможный false positive)
- `styles.css:5723` — `.admin-user-card` (настоящий tell; совпадает с запретом DESIGN.md)

**Visual overlays:** не запускались (browser automation недоступна в сессии).

## Overall Impression

Продукт ощущается зрелым по структуре: sidebar + editor + admin + AI + share, кастомные компоненты, shortcuts, reduced motion. Главная возможность — привести визуальный язык рабочих экранов в соответствие с зафиксированным DESIGN.md: убрать «неоновый» спектр и декоративный AI-брендинг, усилить спокойствие и доверие.

## What's Working

1. **Компонентная дисциплина** — IconButton, Tooltip, CustomSelect, Modal, ToastHost; нет native alert/select; aria-label на toolbar groups.
2. **Power-user слой** — Command Palette, богатые shortcuts (Ctrl+S, Ctrl+Shift+P, Ctrl+\\ и др.), горизонтальный скролл табов админки.
3. **Адаптив** — breakpoints 820px/520px: overlay sidebar, схлопывание admin cards, AI panel на всю ширину viewport.

## Priority Issues

### [P1] Расхождение палитры с DESIGN.md
**Why:** В `:root` заданы `--accent-3` (#7a5cff), `--accent-4` (#c04dff), `--accent-5` (#ff2f9a), фиолетовый `--line-strong` — это ближе к anti-reference «generic AI/SaaS», чем к trust blue + teal из DESIGN.md. Подрывает обещание «calm, modern, clear».
**Fix:** Свести рабочую палитру к токенам DESIGN.md; оставить 1 primary blue + teal для operational + semantic colors; убрать magenta/purple из shell/панелей.
**Suggested command:** `$impeccable colorize app/front`

### [P1] AI assistant как визуальный бренд, а не инструмент
**Why:** `.ai-assistant__orb`, pulse animation, particles, drop-shadow glow на FAB — типичный AI-chat affordance; PRODUCT.md прямо запрещает pseudo-chat как identity.
**Fix:** FAB без орба/частиц; состояние через border/иконку; motion только на open/close; reduced motion уже есть — применить к ai-pulse.
**Suggested command:** `$impeccable quieter app/front/src/features/ai`

### [P1] Side-tab на admin user cards
**Why:** `border-left: 3px solid` на `.admin-user-card` — детектор и DESIGN.md совпадают; cheap AI tell в плотной админке.
**Fix:** Выделение self/selected через background tint или leading icon, не цветную полосу.
**Suggested command:** `$impeccable polish app/front/src/features/admin`

### [P2] Пустые состояния не обучают
**Why:** `.empty-editor` / `.empty-state` — только muted текст («Выберите заметку»); нет CTA создать заметку, нет подсказки про дерево/поиск.
**Fix:** Empty state с primary action + одна строка контекста; для дерева — «Создать заметку».
**Suggested command:** `$impeccable onboard app/front/src/features/notes`

### [P2] Декоративный фон конкурирует с задачей
**Why:** `AmbientCubes` на auth, sidebar, workspace, public share добавляет движение и цветовой шум в зоне письма.
**Fix:** Оставить на login/public (expressive), убрать или сильно приглушить в authenticated workspace.
**Suggested command:** `$impeccable quieter app/front/src/components/AmbientCubes.tsx`

## Persona Red Flags

**Alex (Power User):** AI settings и admin user card — много полей в одной строке; tab admin на мобиле ок, но редактирование пользователя = 2 ряда без bulk.

**Jordan (First-Timer):** Пустой редактор без следующего шага; toolbar — 5 icon groups без текстовых подписей (только tooltips); вход — только стрелка без текста «Войти» на кнопке submit.

**Sam (Accessibility):** Focus-visible широко; риск color-only статусов в AI/admin chips; icon-only auth submit имеет aria-label — ок.

**Maya (Daily Writer, project):** AmbientCubes + AI glow отвлекают от writing flow; хочет «tool disappears» — сейчас UI напоминает о себе декором.

**Dmitry (Admin, project):** Плотность users/activity приемлема, но side-tab и uppercase micro-labels в integration fields добавляют шум без IA-выгоды.

## Minor Observations

- Uppercase micro-labels в AI settings и admin integration — плотно, но для form labels допустимо по DESIGN micro; не section eyebrows.
- `copy-field` с border + tinted background — проверить ghost-card rule.
- Login pre-fill `admin/admin` — только dev, но визуально сбивает при демо.
- Blockquote `border-left: 3px` — editor semantic; не card callout.
