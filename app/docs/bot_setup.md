# Telegram/VK Bot Setup

Короткая инструкция для подключения внешних ботов Notes AI. Глобальная настройка находится в админке: `Панель администратора` -> `Интеграции`. Пользовательская привязка аккаунта находится в настройках Notes AI.

## Общая Схема

1. Администратор создает Telegram-бота или VK-бота сообщества.
2. В админке заполняет webhook/callback URL, token, secret и provider-специфичные поля.
3. Сохраняет интеграцию и проверяет подключение.
4. Пользователь включает бота в настройках Notes AI и генерирует одноразовый код.
5. Пользователь отправляет код боту. Backend связывает внешний Telegram/VK account с текущим аккаунтом Notes.

Бот работает через общий Notes AI pipeline и получает только те tools, которые разрешены глобальными настройками, пользовательскими настройками и ролью пользователя.
Голосовые сообщения Telegram/VK поддерживаются после привязки аккаунта: backend временно скачивает audio/voice файл в память, проверяет лимит 25 MB, распознает его через AI provider пользователя и выполняет расшифрованную команду как обычный текст. Для этого provider должен поддерживать OpenAI-compatible `/audio/transcriptions`; модель задается env `AI_TRANSCRIPTION_MODEL`, по умолчанию `whisper-1`.

## Telegram

1. Открыть Telegram и через поиск найти `@BotFather` - официальный бот Telegram для создания и управления ботами.
2. Отправить `@BotFather` команду `/newbot`.
3. Задать display name и username, который заканчивается на `bot`.
4. Скопировать token, который выдаст `@BotFather`.
5. В админке Notes открыть `Интеграции` -> `Telegram`.
6. Вставить публичный HTTPS webhook URL backend в `URL вебхука`. Endpoint приложения: `/api/ai/bots/telegram/webhook`.
7. Задать `Секрет вебхука`. Он должен совпадать с secret token webhook-запросов Telegram. Можно сгенерировать из UI.
8. Вставить token в `Токен бота`.
9. Сохранить настройки, включить бота и нажать проверку подключения.
10. В Telegram отправить созданному боту `/start`.
11. В настройках Notes AI создать код привязки Telegram и отправить этот код боту.

Важно:

- Token и secret хранятся на backend в зашифрованном виде.
- Полный token после сохранения не отображается, только безопасная маска.
- Для production нужен публичный HTTPS URL, доступный Telegram.

## VK

1. Создать или открыть VK community.
2. В `Управление` -> `Сообщения` включить сообщения сообщества и возможности бота.
3. В `Управление` -> `Работа с API` открыть настройки API сообщества.
4. Создать community access token с правами на сообщения.
5. В админке Notes открыть `Интеграции` -> `VK`.
6. Вставить публичный HTTPS callback URL backend в `URL callback`. Endpoint приложения: `/api/ai/bots/vk/webhook`.
7. Задать `Секретный ключ` в VK и в Notes. Можно сгенерировать из UI.
8. Вставить token в `Токен доступа`.
9. Указать `ID группы`.
10. Скопировать confirmation code из VK в поле `Код подтверждения`.
11. Включить event type `message_new`.
12. Сохранить настройки, включить бота, подтвердить сервер в VK и нажать проверку подключения.
13. В настройках Notes AI создать код привязки VK и отправить этот код боту.

Важно:

- Access token и secret key хранятся на backend в зашифрованном виде.
- Полный access token после сохранения не отображается, только безопасная маска.
- Для production нужен публичный HTTPS URL, доступный VK Callback API.

## Права И Лимиты

- Глобальные лимиты задаются в админке: сообщения, чтение, изменения.
- Пользовательские лимиты и доступы задаются в настройках Notes AI.
- Доступ к секретным значениям полей данных должен быть разрешен и глобально, и пользователем.
- Изменения заметок требуют соответствующих permissions. Если включено подтверждение, опасные действия уходят в pending action и выполняются только после подтверждения.

## Диагностика

- `Проверить подключение` в админке проверяет token/provider-connection и обновляет статус последней проверки.
- Если webhook не приходит, проверить публичный HTTPS URL, secret, token и включенные события provider.
- Если бот отвечает, но не видит данные, проверить привязку аккаунта, пользовательские permissions и лимиты.
